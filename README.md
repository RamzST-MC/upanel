# UPanel — панель управления Ubuntu-сервером

Лёгкая веб-панель на PHP (аналог Brainy/ISPmanager с урезанным, но рабочим
функционалом), которая ставится на чистый Ubuntu 22.04/24.04 одним скриптом.

## Что умеет (из коробки)

- **Дашборд** — базовая статистика сервера, последние действия
- **Управление сервером** — старт/стоп/рестарт служб (nginx, php-fpm, mysql, ssh, ufw, почта, cron)
- **Сайты** — создание/удаление nginx-виртхостов с PHP-FPM, привязка версии PHP
- **PHP версии** — установка дополнительных версий PHP (через ppa:ondrej/php)
- **Логи сайтов** — просмотр access/error логов nginx по каждому домену
- **База данных** — создание/удаление баз MySQL/MariaDB и пользователей
- **Почтовый сервер** — управление Postfix/Dovecot/SpamAssassin/ClamAV (опционально)
- **Почтовые аккаунты** — локальные почтовые пользователи
- **DNSBL** — проверка IP по чёрным спискам (Spamhaus и др.)
- **DNS зоны** — создание базовых зон bind9 (опционально)
- **Файловый менеджер** — просмотр/загрузка/удаление файлов в /var/www
- **Web Shell** — выполнение команд от root (используйте осторожно!)
- **CRON** — управление заданиями root-crontab
- **Мониторинг служб / информация о сервере / менеджер процессов**
- **Сертификаты SSL** — выпуск и продление Let's Encrypt через certbot
- **Резервное копирование** — задания бэкапов директорий в tar.gz
- **Firewall (UFW)** — управление правилами
- **Хост-аккаунты** — системные Linux-пользователи

## Установка

```bash
# скачайте/скопируйте всю папку на сервер, затем:
cd upanel
sudo bash install.sh --admin-user admin --admin-pass 'СложныйПароль123!' --port 9999
```

Опции:

- `--port <N>` — порт панели (по умолчанию 9999)
- `--admin-user <name>` — логин администратора (по умолчанию admin)
- `--admin-pass <pass>` — пароль (если не задать — сгенерируется случайный и будет выведен в конце)
- `--with-mail` — установить и настроить Postfix + Dovecot + SpamAssassin + ClamAV
- `--with-dns` — установить bind9 для DNS-зон
- `--php-version <ver>` — версия PHP для FPM-сокета панели (по умолчанию — системная)

После установки скрипт выведет адрес панели, логин и пароль.

## ⚠️ Безопасность — обязательно прочитать

Панель работает от `www-data`, которому выданы точечные `sudo`-права без пароля
на управление сервером (systemctl, ufw, mysql, certbot, useradd/userdel,
crontab, файловые операции и т.д. — см. `/etc/sudoers.d/upanel`). По сути,
**доступ к панели = root-доступ к серверу**. Поэтому:

1. Не открывайте порт панели в публичный интернет без необходимости.
   Ограничьте доступ через UFW только своим IP/VPN:
   ```bash
   sudo ufw delete allow 9999/tcp
   sudo ufw allow from <ВАШ_IP> to any port 9999 proto tcp
   ```
2. Смените пароль сразу после первого входа (раздел «Безопасность» → «Смена пароля»).
3. Для продакшна поставьте перед панелью reverse-proxy с HTTPS (nginx/Caddy)
   и, по желанию, Basic Auth в дополнение к логину панели.
4. Модуль **Web Shell** даёт полный root-доступ через веб-форму — при желании
   можно закомментировать пункт меню `webshell` в `app/src/menu.php` и удалить
   `app/src/pages/webshell.php`, если он не нужен.

## Структура проекта

```
upanel/
  install.sh           # установочный скрипт
  upanel-helper.sh      # root-хелпер (устанавливается в /usr/local/bin/upanel-helper)
  app/
    public/             # веб-корень (index.php, assets/)
    src/
      bootstrap.php      # конфиг, БД, вспомогательные функции
      menu.php           # структура бокового меню
      pages/              # по одному файлу на раздел панели
      templates/layout.php
    bin/create_admin.php # CLI-создание/сброс пароля администратора
    data/                 # SQLite база панели (создаётся автоматически)
```

## Сброс пароля администратора

```bash
sudo -u www-data php /var/www/upanel/bin/create_admin.php admin НовыйПароль123
```
